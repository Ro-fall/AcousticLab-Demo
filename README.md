# AcousticLab Demo

一个在浏览器中运行的轻量声学信号观测工具。它直接调用电脑麦克风，将声音信号以清晰的交互界面呈现出来，适合声学学习、课堂演示与快速实验。

## 当前功能

- 开启或停止电脑麦克风采集
- 两种输入源：实时麦克风采集，或测试/导入信号
- 生成可设频率的正弦波或方波，或导入本地音频文件（循环分析）
- 实时显示**过去时域**音频波形
- 可在时域波形中叠加基于解析信号的 Hilbert 包络
- 实时频谱（FFT）与主频识别
- 可选择 1,024–16,384 点 FFT 分辨率
- 共用一套帧处理链路：Hann 加窗 → FFT → STFT / Mel / MFCC
- 滚动声谱图 / 时频图（STFT），保存近期频谱帧历史
- 感知频率尺度的 Mel 声谱图（48 个 Mel 三角滤波器）
- 13 维 MFCC（Mel Frequency Cepstral Coefficients，DCT-II）特征图
- 实时特征：RMS、峰值、主频、相对声压级（dBFS）
- 调整观测窗口（20–200 ms）
- 自定义频谱与声谱图的显示频率上下限
- 显示输入采样率与采集状态
- 音频只在浏览器本机处理，不上传服务器

## 操作说明

桌面工作台左侧依次呈现紧凑时域监视、实时频谱、滚动声谱图与特征指标；右侧面板用于控制麦克风、时域窗口、频率显示范围和 FFT 点数。

- “实时采集”使用电脑麦克风；“测试/导入”可生成正弦波或选择本地音频文件。它们共享同一套分析视图与指标。
- FFT 点数越大，频率分辨率越高，但更新响应会略慢。
- 调整“显示频率范围”会同步更新频谱和声谱图的坐标及显示内容。
- STFT、Mel 声谱图与 MFCC 共用同一份实时分析帧：先对采样帧施加 Hann 窗，再做 FFT；Mel 使用 48 个三角滤波器汇聚频谱能量，MFCC 对对数 Mel 能量做 DCT-II 并保留前 13 维。右侧“分析参数”会显示当前帧长、更新率和频率分辨率。
- 声谱图从右向左滚动：右侧为最新声音，左侧为较早的频谱帧。

## 快速开始

需要安装 [Node.js](https://nodejs.org/)（建议 LTS 版本）。

```bash
npm install
npm run dev
```

随后访问终端中显示的本地地址（通常是 `http://localhost:5173`），点击“开启麦克风”，并在浏览器弹窗中允许访问麦克风。

## 技术选型

- Vue 3 + TypeScript + Vite
- Web Audio API：本地获取和分析音频信号
- Canvas：低延迟绘制波形、频谱与时频历史

## 分析参数

分析帧长度由 FFT 点数和输入采样率决定，例如 48 kHz、4,096 点时为约 85.3 ms；频率分辨率为采样率 / FFT 点数。分析帧最多每 40 ms 更新一次（25 Hz）。频谱、STFT、Mel 与 MFCC 使用同一份加窗帧，因此它们反映的是同一时刻的声音内容。

## 使用提示

浏览器麦克风权限通常只在 `localhost` 或 HTTPS 页面下可用。请优先使用最新版 Chrome、Edge 或 Firefox。

“LEVEL” 使用 dBFS（相对于数字满刻度）显示，方便观察信号强弱；若需要可比较的物理声压级 dB SPL，需使用已知声压级的校准声源，对每个麦克风分别校准。
